# Bridge Engine — Product + Infrastructure Roadmap

## Core Vision

Bridge Engine is not a traditional education platform.

It is:
- adaptive momentum infrastructure
- ADHD-friendly learning architecture
- behavioral engagement system
- project-based skill engine
- retention-oriented growth platform

The goal is:
> make people WANT to continue learning.

---

# Product Pillars

## 1. Adaptive Learning

System adapts based on:
- energy level
- overwhelm
- flow state
- completion rate
- project interests
- user behavior
- attention patterns

Future:
- archetype detection
- predictive burnout prevention
- dynamic challenge scaling
- path branching
- personalized momentum curves

---

## 2. Momentum Engineering

The system should:
- reduce friction to start
- increase momentum while engaged
- reduce shame after breaks
- create visible progress loops
- maintain emotional engagement

Core mechanics:
- tiny wins
- streaks
- XP
- skill trees
- visible artifacts
- continuation paths
- momentum recovery
- challenge mode

---

## 3. Retention Architecture

Future systems:
- push notifications
- mobile reminders
- Discord integrations
- browser extension
- focus sessions
- desktop focus agent
- contextual reminders
- adaptive nudges

Future engagement examples:
- "You were in flow mode yesterday. Want a 5-minute restart?"
- "You are 1 step away from leveling up coding."
- "You completed finance faster than average this week."

# Data Collection Strategy

Collect ONLY what improves adaptation.

Examples:
- completion speed
- step skips
- overwhelm signals
- flow state patterns
- preferred session lengths
- engagement loops
- restart success rate

Avoid unnecessary sensitive data.

# Privacy + Security

Important:
This matters enormously if monetized.

## Required later

- privacy policy
- terms of service
- consent systems
- export/delete account data
- encryption at rest
- HTTPS everywhere
- auth system
- role-based access
- API rate limiting
- secure session management
- audit logging

## Strong Recommendation

Avoid storing:
- unnecessary personal data
- raw behavioral recordings
- medical claims
- mental health diagnoses

Frame carefully:
- productivity
- focus
- adaptive learning

NOT:
- therapy
- treatment
- diagnosis
